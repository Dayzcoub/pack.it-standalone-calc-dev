# Accessibility

## Purpose

PACK.IT must remain usable on mobile devices in real field conditions.

## Rules

- touch targets must be comfortable
- no hover-only interaction
- readable contrast
- safe area support
- clear focus states later
- clear error and warning text
- important actions need confirmation when destructive

## Scene UI

3D interactions must have accessible alternatives where possible.

For example, object position and rotation can be edited through Object Inspector fields.

## Task 001

Task 001 should use shared components and avoid inaccessible patterns from the start.
