# Onboarding and Help

## Purpose

The first launch should explain the Project Scene First workflow without long tutorials.

## Required concepts

- create project
- add stage
- add truss
- add LED
- add object from library
- select and edit object
- open summary
- generate PDF

## Empty states

Empty states must suggest the next action.

Examples:

- no projects: create project
- empty scene: add stage or open template
- no selected object: tap object or add one

## Task 001

Task 001 can use placeholder onboarding text and empty states.
