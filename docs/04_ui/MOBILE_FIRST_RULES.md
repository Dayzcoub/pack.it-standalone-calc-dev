# Mobile First Rules

## Status

Accepted.

## Platform priority

1. iPhone
2. Android
3. iPad and tablets
4. Desktop browsers

Desktop is a supported platform, but not the primary design target.

## Rule

Every new screen must be designed for phone usage first.

Desktop layouts are derived from the mobile design.

## Interaction rules

- touch-first
- no hover-only functionality
- safe area aware
- one-hand friendly where practical
- large touch targets
- bottom-sheet preferred for inspectors and builders

## Validation rule

A feature is not complete until it has been tested on mobile.
