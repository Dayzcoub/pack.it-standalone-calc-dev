# PACK.IT Release Strategy

## Versioning

PACK.IT has not been publicly released yet.

Use semantic pre-release product versions:

```text
0.1.x — Alpha architecture foundation
0.2.x — Scene object system and builders
0.3.x — BOM from SceneModel
0.4.x — PDF from ProjectModel
0.5.x — Asset Library and GLB import foundation
0.6.x — Audio/Light manual placement
0.7.x — project save/load polish
0.8.x — Beta
0.9.x — Release Candidate
1.0.0 — first public release
```

## Historical archive numbers

Old archive numbers and legacy app versions are internal checkpoints only.

They must not be presented as PACK.IT product versions.

## Release rule

A version is a product version only when it belongs to the new PACK.IT Alpha/Beta/Release line.
