# PACK.IT Vision

## Status

```text
PACK.IT Alpha 0.1.0
Project Scene First
```

PACK.IT is a standalone/offline mobile-first 3D constructor for technical event packages.

The product helps event production teams build a technical package in one shared 3D scene and generate structured outputs from that scene.

## Product promise

Create the event technical package visually, then generate equipment list, weight, price, power notes and PDF from the same project model.

## Not a calculator bundle

PACK.IT is not three separate calculators for Stage / Truss / LED.

Stage, Truss and LED are scene object groups created through guided builders.

## Long-term direction

The long-term product is a practical field/office tool for:

- stage structures;
- truss structures;
- LED screens;
- audio placement;
- lighting placement;
- power planning;
- decor and generic 3D objects;
- technical documentation.

## Release philosophy

`1.0.0` is the first public release.

Everything before it is Alpha/Beta and can still change architecture if needed.
