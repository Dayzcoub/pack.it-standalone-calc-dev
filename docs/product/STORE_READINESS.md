# Store Readiness

## Purpose

PACK.IT should be designed with future App Store and Google Play release in mind.

## Required later

- app icon
- splash screen
- support URL
- privacy policy
- privacy labels
- data safety form
- permissions review
- offline behavior check
- PDF/share check
- crash-free basic testing

## Alpha rule

Do not add functionality that creates store privacy problems without product decision.

## Task 001

Task 001 should not request unnecessary permissions.
