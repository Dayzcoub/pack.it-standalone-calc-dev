# MVP Cut Line

## Alpha 0.1.0 includes

- app shell
- project creation
- scene creation
- scene viewport
- selection
- object inspector foundation
- save and load
- Add Stage entry point
- Add Truss entry point
- Add LED entry point
- demo projects

## Explicitly not included in Alpha 0.1.0

- final BOM engine
- final pricing engine
- final PDF engine
- venue editor
- power planning
- rigging planning
- AI assistant
- cloud sync
- collaboration server
- telemetry
- analytics
- advanced asset import
- final validation engine

## Rule

If a feature is not required for Scene Shell MVP, it should be postponed.

The goal of Alpha 0.1.0 is proving the architecture, not delivering the entire product.
