# Backup and Export Policy

## Purpose

Users must be able to keep control of their local project data.

## Export directions

- PDF
- `.packit` project file later
- JSON backup later
- BOM export later

## Backup direction

Local projects should be stored in a backup-friendly way where platform rules allow.

Do not promise guaranteed cloud sync.

## Rule

No backend export is required in Alpha.

User-controlled files are the preferred first path.

## Task 001

Task 001 should keep ProjectModel serializable and storage versioned.
