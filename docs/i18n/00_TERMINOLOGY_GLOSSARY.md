# 00. Terminology Glossary

## 1. Purpose

PACK.IT must use consistent Russian and English terminology in UI, PDF, help texts and Store copy.

Do not translate technical terms randomly.

## 3. Tone rules

Avoid:

- guaranteed safe;
- certified;
- approved for mounting;
- engineering verified;
- magically optimized.

Prefer:

- reference calculation;
- based on entered data;
- check equipment documentation;
- verify before installation;
- requires qualified specialist review.

## 4. Acceptance

Accepted when RU/EN UI and PDF terms stay consistent and do not overpromise safety.
