# Add Stage Builder

Add Stage is a guided builder.

It creates or updates a StageGroup inside the shared SceneModel.

It is not an independent calculator application.

## Inputs

- width
- depth
- height
- deck type
- stairs option
- closure option

## Output

- StageGroup
- child scene objects
- object metadata
- future BOM contribution data

## Rule

After creation, the scene owns the StageGroup.

Further editing happens through Object Inspector and controlled scene actions.
