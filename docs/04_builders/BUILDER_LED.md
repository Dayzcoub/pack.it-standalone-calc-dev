# Add LED Builder

Add LED is a guided builder.

It creates or updates a LedGroup inside the shared SceneModel.

It is not an independent calculator application.

## Inputs

- screen width
- screen height
- cabinet size
- hanging mode
- standing mode
- support options

## Output

- LedGroup
- cabinet objects
- support objects
- future project contribution data

## Rule

LED logic becomes builder and object contribution logic.

Final project output comes from SceneModel.
