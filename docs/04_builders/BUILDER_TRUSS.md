# Add Truss Builder

Add Truss is a guided builder.

It creates or updates a TrussGroup inside the shared SceneModel.

It is not an independent calculator application.

## Initial modes

- Portal
- Frame
- Stool
- Manual later

## Output

- TrussGroup
- straight sections
- nodes and corners
- supports and bases where needed
- future BOM contribution data

## Rule

Existing truss domain rules are reused as builder logic and object contribution logic.

The final project output still comes from SceneModel.
