## 3. Full description draft — Russian

```text
ПАК.ИТ Калькуляторы — мобильное приложение для быстрых технических расчётов сценических конструкций, ферм и LED-экранов.

Приложение помогает подготовить расчёт сцены, ферменной конструкции или LED-экрана прямо на телефоне: указать размеры, выбрать параметры, получить схему, комплектацию, вес, стоимость и PDF-файл для отправки.

Возможности:
• калькулятор сцены;
• калькулятор ферм;
• калькулятор LED-экранов;
• схема конструкции;
• комплектация / BOM;
• расчёт веса и стоимости;
• локальное сохранение расчётов;
• экспорт PDF;
• отправка PDF через системное меню;
• работа офлайн без аккаунта.

Приложение не требует регистрации и в первой версии хранит расчёты локально на устройстве.

Важно: расчёты являются справочными и не заменяют инженерную проверку, паспортные данные оборудования, требования производителя, нормы безопасности и ответственность квалифицированного специалиста на площадке.
```

## 4. Full description draft — English

```text
PACK.IT Calculators is a mobile app for quick technical calculations of stage platforms, truss structures and LED screens.

The app helps prepare a calculation directly on your phone: enter dimensions, choose parameters, view a scheme, equipment list, weight, price and generate a PDF file for sharing.

Features:
• Stage calculator;
• Truss calculator;
• LED screen calculator;
• Construction scheme;
• Equipment list / BOM;
• Weight and price summary;
• Local saved calculations;
• PDF export;
• Native PDF sharing;
• Offline use without an account.

The app does not require registration and the first version stores calculations locally on the device.

Important: calculations are for reference only and do not replace engineering verification, equipment documentation, manufacturer requirements, safety regulations or the responsibility of a qualified specialist on site.
```
