# PDF Engine

PDF Engine generates documents from ProjectModel.

PDF must not be generated from isolated calculator screens.

## Input

- ProjectModel
- SceneModel
- BOM snapshot
- price snapshot
- weight snapshot
- scene snapshots

## MVP content

- project title
- event metadata
- isometric scene snapshot
- top view snapshot
- BOM
- weight
- optional price
- warnings
- version metadata

## Rule

PDF output is a project document, not a calculator printout.
