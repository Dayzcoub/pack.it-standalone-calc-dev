# Output Modes

## Purpose

PACK.IT needs different outputs for different audiences.

## Initial modes

- Client mode
- Tech mode

## Client mode

Client mode can hide technical details and internal notes.

It can focus on clear layout, summary and optional price.

## Tech mode

Tech mode can include more details:

- BOM
- warnings
- dimensions
- object notes
- power notes
- rigging notes later

## Rule

Both modes are generated from ProjectModel.

Do not create separate calculator PDFs.
