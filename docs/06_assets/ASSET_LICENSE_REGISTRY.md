# Asset License Registry

## Purpose

Every external asset must have traceable origin and license status.

This includes 3D models, textures, icons, illustrations and reference files.

## Required fields

- asset id
- file path
- source
- author
- license
- commercial use allowed
- modification allowed
- attribution required
- notes

## Rule

Do not ship unclear assets in production.

If license is unknown, mark the asset as needs-check.

## Task 001

Task 001 does not need real asset inventory.

It should keep a place for the registry.
