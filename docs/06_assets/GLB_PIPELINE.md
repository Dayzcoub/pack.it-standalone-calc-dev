# GLB Pipeline

## Primary format

PACK.IT uses GLB / GLTF as the primary 3D asset format.

## Use cases

- bundled object library;
- manual object placement;
- future custom user import;
- visual references for audio, light, power and decor objects.

## Requirements

Assets should be optimized for mobile use:

- reasonable polygon count;
- clean origin;
- real-world scale in meters;
- meaningful file names;
- no baked UI elements;
- no unnecessary heavy textures.

## Task 001

Only contracts and placeholder folders/entry points are required.

Production assets are later tasks.
