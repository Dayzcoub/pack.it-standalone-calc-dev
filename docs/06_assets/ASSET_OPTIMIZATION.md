# Asset Optimization

## Purpose

3D assets must stay mobile-friendly.

## Rules

- avoid heavy models
- avoid unnecessary high resolution textures
- use real-world scale
- keep clean origins
- use meaningful filenames
- prefer reusable assets
- document source and license where needed

## Diagnostics later

The app or build tools can warn about heavy assets later.
