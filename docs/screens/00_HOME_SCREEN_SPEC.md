# 00. Home Screen Spec

## 1. Purpose

Home is the launcher for the three calculators and recent work.

## 2. Required content

- PACK.IT logo/title;
- subtitle;
- Stage card;
- Truss card;
- LED card;
- recent calculations;
- bottom navigation: Home / Saved / Settings.

## 3. Calculator cards

Each card includes:

- icon/illustration;
- title;
- short description;
- last calculation snippet if available;
- chevron/open action.

## 4. States

```text
first launch
normal with recent calculations
no recent calculations
settings fallback
```

## 5. Acceptance

- no horizontal overflow;
- cards are touch-friendly;
- all three calculators are visible/reachable;
- no FEG brand;
- RU/EN labels supported.
