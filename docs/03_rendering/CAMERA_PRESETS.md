# Camera Presets

## Purpose

Camera Presets provide stable views for work, PDF and communication.

## Built-in views

- perspective
- isometric
- top
- front
- side

## Future presets

- client view
- technician view
- custom bookmark
- PDF view

## Data

A camera preset should store:

- id
- name
- position
- target
- zoom
- projection type
