# Development Lifecycle

## Purpose

Defines the recommended order of implementation and validation.

## Stages

- Architecture Freeze
- Foundation Layer
- Scene Core
- Builders MVP
- Catalog Layer
- Asset Layer
- BOM Layer
- Pricing Layer
- Document Export Layer
- Validation Layer
- Venue Layer
- Advanced Object Layer
- Future AI Layer

## Definition of Done

- build succeeds
- type checks succeed
- save and load work
- mobile validation completed
- regression checks completed

## Task Rule

Prefer small isolated tasks.

Keep architecture boundaries intact.
