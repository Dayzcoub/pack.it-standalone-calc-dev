# Pre-Code Gate

## Purpose

Pre-Code Gate defines when PACK.IT documentation is ready enough to start Task 001.

## Required before code

- Project Scene First decision is documented
- Product versioning is documented
- ProjectModel is documented
- SceneModel is documented
- CatalogModel is documented
- Object System is documented
- Scene Graph is documented
- UI contract is scene-first
- Task 001 is updated
- Security and privacy rules are documented
- Schema versioning is documented
- Coordinate system is documented
- Action System is documented
- Test strategy is documented
- CI gates are documented
- Legal disclaimers are documented

## Start command

Implementation starts only after explicit command:

```text
gотово, начинаем Task 001
```

## Rule

If a new critical architecture concern appears before code, document it before implementation.
