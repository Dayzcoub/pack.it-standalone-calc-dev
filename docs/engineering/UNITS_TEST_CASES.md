# Units Test Cases

## Purpose

Units must not be mixed between meters, millimeters, kilograms, watts and kilowatts.

## Test direction

Add test cases for:

- meters to millimeters formatting
- millimeters to meters normalization
- kilograms summary
- watts to kilowatts display
- currency display
- decimal separator by locale

## Scene rule

Internal SceneModel units are meters.

Display formatting happens through locale and units adapters.

## Task 001

Task 001 should include the first simple unit normalization tests if practical.
