# ADR 0003 — GLB / GLTF Asset Format

## Status

Accepted for Alpha planning.

## Context

PACK.IT needs reusable 3D assets for manual placement and technical object visualization.

## Decision

Use GLB / GLTF as the primary 3D asset format.

## Consequences

- asset pipeline must keep models mobile-friendly
- asset scale and origin must be controlled
- custom import can start with GLB / GLTF later
- other formats are future optional work
