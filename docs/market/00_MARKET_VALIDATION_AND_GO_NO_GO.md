# 00. Market Validation and Go / No-Go

## 1. Current decision

Decision:

```text
Proceed with PACK.IT standalone calculators, but only as a narrow professional MVP first.
```

Do not treat the first release as a full CRM, ERP, CAD or engineering certification tool.

## 2. Market hypothesis

There is likely a useful niche between:

- large rental/ERP systems;
- professional CAD/rigging tools;
- manual Excel/notes/calculator workflows.

PACK.IT standalone calculators should target this gap:

```text
fast mobile reference calculations for Stage / Truss / LED with scheme, BOM, price and PDF.
```

## 3. Positioning

Recommended positioning:

```text
PACK.IT — быстрые расчёты сцены, ферм и LED на телефоне.
```

Alternative phrasing:

```text
Офлайн-калькулятор для прокатчика: схема, комплектность, вес, цена и PDF за пару минут.
```

Do not position v1.0 as:

- CRM;
- warehouse system;
- full rental ERP;
- Vectorworks replacement;
- certified engineering calculation;
- cloud production platform.

## 4. Target users

Primary users:

- small/medium equipment rental companies;
- stage/truss/LED rental operators;
- production managers;
- technical directors;
- stage/truss technicians;
- LED technicians;
- event production freelancers.

## 5. First MVP value

The first useful product must answer:

```text
Can I calculate a construction quickly enough to use it in a real client/work conversation?
```

Minimum useful loop:

```text
open app → choose calculator → enter size/options → get scheme/BOM/price → save → export/share PDF
```

## 6. MVP scope for validation

Include:

- Stage calculator;
- Truss calculator;
- LED calculator;
- separate saved calculations;
- one PDF export;
- native share;
- offline use;
- safety disclaimer.

Exclude from first validation MVP:

- CRM;
- clients/projects database;
- cloud sync;
- Pro/IAP;
- ads;
- full custom catalog UI;
- full 3D constructor;
- online marketplace;
- team/workspace features.

## 7. Validation test

Before heavy Pro/cloud development, test with real users.

Suggested first validation group:

```text
10–20 real users from rental/production/stage/LED/truss context.
```

Success signals:

- 5+ users create real calculations;
- 3+ users export/share PDF or say the PDF is usable;
- 2–3 users say they would pay for Pro/advanced features;
- users ask for repeated similar improvements;
- at least some users return after a few days.

Failure signals:

- users only open once and do not calculate;
- PDF is not considered useful;
- calculations do not match real workflow;
- too many required catalog assumptions are missing;
- users prefer existing Excel/manual workflow and see no gain.

## 8. Commercial view

Do not expect App Store / Google Play organic discovery alone to drive growth.

Likely acquisition channels:

- Telegram/professional chats;
- YouTube/short demos;
- direct rental company contacts;
- existing production network;
- equipment dealers/manufacturers later;
- demos showing PDF output and real time saved.

## 9. Monetization hypothesis

v1.0:

```text
free, no ads
```

Future Pro may include:

- combined PDF;
- technical PDF;
- custom truss catalogs;
- custom LED cabinets;
- advanced price profiles;
- JSON/CSV export;
- project packages;
- unlimited saved calculations if Free is limited later.

Preferred first paid model to evaluate:

```text
one-time Pro unlock or lifetime license
```

Subscription is more suitable later if cloud sync, live catalogs or ongoing services are added.

## 10. Go / No-Go rule

Go:

- MVP can be built without huge infrastructure;
- calculations are useful for the owner’s own rental workflow;
- first users validate PDF/usefulness;
- scope remains tight.

No-Go or pause:

- MVP becomes too broad before release;
- core calculations cannot be trusted/tested;
- no real users find value;
- Store/legal/privacy overhead grows due to unnecessary features.

## 11. Final recommendation

Recommendation:

```text
Proceed, but ship a narrow MVP first.
```

Success depends less on Store launch and more on:

- fast real workflow;
- correct calculations;
- good PDF;
- professional mobile UX;
- direct validation with real rental/production users.
