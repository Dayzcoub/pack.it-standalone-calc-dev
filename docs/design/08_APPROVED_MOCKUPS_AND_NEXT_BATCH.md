## 3. Realism note

This direction is technically achievable.

However, implementation may simplify:

- 3D card illustrations;
- ultra-detailed textures in diagrams;
- exact mockup shadows;
- exact amount of text visible on smaller phones.

Implementation must preserve:

- overall dark premium technical mood;
- PACK.IT brand;
- metric cards;
- tabbed calculator structure;
- scheme viewport with controls;
- saved calculations card system;
- bottom action bar.

## 6. Rule before coding

Do not start the application foundation code until:

- design docs are committed;
- visual direction is approved;
- asset requirements are listed;
- the required mockup set is complete enough for Codex to follow without inventing layout.
