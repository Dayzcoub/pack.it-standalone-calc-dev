# File-Based Collaboration Future

## Purpose

PACK.IT has no accounts or cloud workspace in Alpha.

Still, users should be able to pass project files to other people later.

## Direction

Collaboration starts as file-based sharing:

- export `.packit`
- send file
- import file on another device
- continue editing locally

## Rule

Do not add backend collaboration in Alpha 0.1.0.

Keep ProjectModel serializable and portable.

## Future

Cloud collaboration is a separate product decision.
