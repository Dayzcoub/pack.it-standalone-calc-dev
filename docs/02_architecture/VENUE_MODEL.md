# Venue Model

## Purpose

Venue Model describes the physical place where the technical package is built.

PACK.IT should not only place objects in empty space. It should be ready to describe the event venue.

## Initial venue data

- venue name
- indoor or outdoor
- floor size
- ceiling height
- walls or boundaries
- existing stage note
- audience zones
- backstage zones
- FOH zone
- doors and access points
- power points
- rigging points later

## Relationship to SceneModel

Venue data belongs to the project scene environment.

Scene objects are placed inside or around the venue.

## Task 001

Task 001 should reserve data structures only.

Full venue editor is a later task.
