# Transform Rules

## Purpose

Transform Rules define what can be moved, rotated or scaled.

## Default rule

Technical objects can be moved and rotated.

Free scale should be disabled for technical objects by default.

A speaker, LED cabinet or truss part must not accidentally become a non-real scale object.

## Allowed transforms

- move
- rotate
- duplicate
- parameter-based resize through builder or inspector

## Restricted transforms

- arbitrary free scale for real equipment
- destructive geometry edits

## Task 001

Task 001 should define transform capability flags.
