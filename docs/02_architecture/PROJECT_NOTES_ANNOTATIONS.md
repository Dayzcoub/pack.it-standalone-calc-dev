# Project Notes and Annotations

## Purpose

Project notes and scene annotations let users add context that is not equipment.

## Examples

- FOH here
- low ceiling
- do not block access
- power point location
- backstage note
- client comment

## Types

- project note
- scene annotation
- object note
- PDF note later

## Rule

Notes should be saved in ProjectModel.

Scene annotations can reference objects or coordinates.

Task 001 should keep space for notes in project metadata.
