# Layer System

## Purpose

Layer System controls visibility and organization of the scene.

## Initial layers

- Stage
- Truss
- LED
- Audio
- Light
- Power
- Rigging
- Decor
- Generic

## Layer state

Each layer can support:

- visible
- locked later
- color/accent later
- count summary later
