# User Modes

## Purpose

User Modes help keep the interface usable while still allowing advanced control.

## Modes

- Quick
- Pro
- Expert

## Quick

Simple fields and common presets.

Good for fast project drafts.

## Pro

More object settings, scene layers, summary controls and project-level outputs.

## Expert

Advanced settings, technical metadata and future manual overrides.

## Rule

User modes change UI complexity.

They must not silently change calculation rules.

## Task 001

Task 001 should reserve the setting and UI concept only.
