# Spatial Query System

## Purpose

Spatial Query System helps find objects by position, area, height, layer or relationship.

## Future examples

- objects on stage
- objects above selected height
- powered objects
- fixtures on a truss group
- objects inside venue boundary

## Use cases

- selection
- validation
- PDF summaries
- BOM grouping
- future search tools
