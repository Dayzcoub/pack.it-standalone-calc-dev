# Attachment Points

## Purpose

Attachment Points describe where scene objects can connect, hang, stand or mount.

They are important for truss, LED, audio, light and rigging.

## Basic data

- id
- parent object id
- local position
- allowed object types
- label
- height
- notes
- validation status

## Examples

- LED hanging point on truss
- light fixture point on truss
- speaker mount point
- venue rigging point
- floor stand point

## Rule

Attachment points are reference and planning data.

They do not certify any load or safety.
