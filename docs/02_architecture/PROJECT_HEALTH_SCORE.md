# Project Health Score

## Purpose

Project Health Score is a future summary of project completeness and risk.

## Examples

A project may lose score when:

- required data is missing
- validation issues exist
- catalog data is estimated
- power planning is incomplete
- rigging notes need review
- objects have missing assets

## Rule

Health score is guidance only.

It must not claim safety or approval.

## Task 001

Task 001 should keep validation data structured enough for future scoring.
