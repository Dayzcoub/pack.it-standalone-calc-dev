# Rigging Model

## Purpose

Rigging Model is separate from Truss Model.

Truss describes structure.

Rigging describes hanging, attachment, motors, slings, shackles, spansets, safety notes and related planning data.

## Initial entities

- rigging point
- hanging point
- motor placeholder later
- sling placeholder later
- shackle placeholder later
- safety note

## Rule

Rigging data in PACK.IT is reference planning data.

It must not claim certification or mounting approval.

## Relationship

Rigging Model connects venue points, truss objects, LED objects, audio objects and light objects.
