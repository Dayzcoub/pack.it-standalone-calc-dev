# Object Library

## Purpose

Object Library is different from Asset Library.

Asset Library stores 3D models and visual assets.

Object Library stores ready technical objects or assemblies.

## Examples

- speaker stack
- line array preset
- LED wall preset
- truss portal preset
- stage plus stairs preset

## Relationship to CatalogModel

An object library item can reference catalog items and asset models.

When inserted, it creates normal SceneObjects and SceneGroups.
