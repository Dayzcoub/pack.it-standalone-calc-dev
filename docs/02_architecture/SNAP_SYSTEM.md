# Snap System

## Purpose

Snap System makes manual placement usable.

Without snapping, arranging technical objects in a 3D scene becomes slow and inaccurate.

## Snap types

- grid snap
- object snap
- edge snap
- center snap
- ground snap
- height snap later

## MVP rule

Task 001 only defines settings and contracts.

Actual snapping can be implemented after basic selection and transforms.

## Settings

Snap settings should be stored in project or user settings:

- enabled
- grid step
- snap to objects
- snap to ground
- snap strength
