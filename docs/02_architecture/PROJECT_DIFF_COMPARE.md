# Project Diff and Compare

## Purpose

Project Diff and Compare is a future feature for comparing two project states.

## Use cases

- compare project versions
- see changed objects
- compare BOM changes
- compare price changes later
- review before export later

## Alpha rule

Do not implement in Task 001.

Keep IDs stable and actions structured so compare becomes possible later.

## Foundation requirements

- stable object IDs
- versioned project data
- action history direction
- serializable ProjectModel
