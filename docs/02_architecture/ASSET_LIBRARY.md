# Asset Library

## Purpose

Asset Library provides reusable 3D objects for manual placement in the PACK.IT scene.

## Initial categories

- Audio
- Light
- Power
- Rigging
- Decor
- Generic 3D

## Primary format

```text
GLB / GLTF
```

## Object modes

```text
visualOnly
catalogLinked
```

`visualOnly` objects are used only for scene visualization.

`catalogLinked` objects are connected to catalog data and can contribute to project outputs.

## MVP rule

Task 001 only needs contracts and placeholder UI entry points.

Production import UI and final asset catalog are later tasks.
