# Power Model

## Purpose

Power Model describes electrical consumers, power points and power planning data.

It is a planning model, not an electrical certification tool.

## Initial entities

- power consumer
- power point
- power line
- power group
- total power summary
- warnings

## Consumer data

A consumer may include:

- object id
- catalog reference
- power in W
- inrush note later
- connector type later
- phase note later

## Output

Power Model can contribute to:

- project summary
- warnings
- PDF
- future cable planning
