# Autosave and Recovery

## Purpose

Users must not lose project work after app close, crash or phone interruption.

## Direction

Autosave should save ProjectModel locally after important actions.

## Recovery

The app should be able to recover the last draft project.

## Drafts

Draft projects can be separate from explicitly named saved projects.

## Task 001

Task 001 should define storage interfaces and leave room for autosave metadata.
