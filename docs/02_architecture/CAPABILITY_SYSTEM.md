# Capability System

## Purpose

Capability System describes what an object can do instead of relying only on object type.

## Examples

- has weight
- has power consumption
- can be suspended
- can stand on floor
- can host attachment points
- contributes to BOM
- contributes to price
- contributes to PDF
- has 3D asset

## Why it matters

Future modules can query capabilities without hardcoding every object type.

## Rule

Capabilities complement object type.

They do not replace validation rules.

## Task 001

Task 001 should reserve capability metadata in object and catalog contracts.
