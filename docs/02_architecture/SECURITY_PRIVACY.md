# Security and Privacy

## Purpose

PACK.IT must be safe for local offline use and store readiness.

## Alpha rule

No accounts, backend, analytics, ads or tracking.

## Data

Project data is local by default.

The app should not send project data to a server.

## Permissions

Request only permissions required for a clear user action.

Examples:

- file import
- file export
- share

## Network

Unexpected network calls are forbidden in Alpha 0.1.0.

## Task 001

Task 001 should keep the app offline by default and add no unnecessary SDKs.
