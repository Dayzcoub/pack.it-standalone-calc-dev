# Templates

## Purpose

Templates allow users to start from common event setups instead of building every project from zero.

## Types

- project templates
- scene templates
- object group templates

## Examples

- small concert stage
- truss portal with LED
- LED wall setup
- audio stack setup
- conference setup later

## Rule

A template creates normal ProjectModel or SceneModel data.

After creation, the user edits it like any other project.

Task 001 only needs to keep the architecture compatible with templates.
