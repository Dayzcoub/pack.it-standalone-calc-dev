# 01. Asset Generation Prompts

## 1. Purpose

This document stores reusable prompts for generating PACK.IT assets consistently.

Generated images are references or source material. Final implementation assets should be exported as individual files with correct names, transparency and sizes.

## 2. Global visual prompt base

Use this base for PACK.IT assets:

```text
Premium dark technical mobile app asset for PACK.IT Calculators, professional event production equipment, graphite and dark blue-gray background, steel teal accent, subtle warm amber highlight, realistic technical details, clean modern SaaS/mobile tool style, high contrast, not cartoonish, not playful, no people, no text unless explicitly requested, no FEG branding.
```

## 3. App icon prompt

```text
Create a premium square rounded app icon for PACK.IT Calculators, dark graphite background, steel teal technical package mark, subtle grid/cube geometry symbolizing stage/truss/LED calculations, clean futuristic professional utility app, high contrast, readable at small size, no extra text except optional stylized PACK.IT mark, no FEG branding, 1024x1024.
```

## 4. Splash prompt

```text
Create a dark premium splash screen for PACK.IT Calculators mobile app, centered PACK.IT logo/mark, graphite technical background, subtle blueprint grid, steel teal glow, minimal, professional field tool, no extra UI, no FEG branding.
```

## 11. Store screenshot board prompt

```text
Create a polished App Store / Google Play screenshot mockup board for PACK.IT Calculators, show mobile app screens for stage, truss and LED calculations, dark premium technical UI, Russian captions, steel teal accent, professional event production tool, realistic phone frames, clean marketing layout, no FEG branding.
```

## 12. Prompt constraints

Always include:

```text
no FEG branding
no random people
no cartoon style
professional technical tool
```

For truss assets always include:

```text
round cylindrical tubes, not square tubes
```

## 13. Post-generation requirements

After generation:

- crop/export individual files;
- remove backgrounds where transparent required;
- verify no wrong text/logos;
- verify truss tube shape;
- save source prompt;
- name files using kebab-case.
