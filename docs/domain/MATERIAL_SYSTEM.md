# Material System

## Purpose

Material System describes physical and visual material properties for scene objects and catalog items.

## Examples

- aluminum
- steel
- wood
- fabric
- LED panel
- plastic

## Use cases

- visual appearance
- weight estimation later
- PDF specification later
- catalog metadata
- asset rendering hints

## Rule

Material data is metadata and should not replace verified catalog weight.

Task 001 should keep material references possible in object and catalog contracts.
