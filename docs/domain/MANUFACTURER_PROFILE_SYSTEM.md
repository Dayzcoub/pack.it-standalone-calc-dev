# Manufacturer Profile System

## Purpose

Manufacturers should be modeled as entities, not repeated text fields.

## Examples

- MDM
- Prolyte
- FBT
- dB Technologies
- Robe
- Martin

## Profile fields

- id
- display name
- website
- product families
- documentation links later
- compatibility notes
- source status

## Relationship

Catalog items can reference a manufacturer profile.
