# Domain Rules Registry

## Purpose

Domain Rules Registry preserves proven Stage, Truss and LED rules while moving to Project Scene First.

The goal is to avoid losing old working calculation knowledge during the architecture reset.

## Rule groups

- Stage rules
- Truss rules
- LED rules
- BOM rules
- pricing rules
- power rules
- PDF rules

## Required metadata

Each rule should later have:

- id
- area
- description
- source
- status
- test coverage
- calculation engine version

## Source statuses

- accepted
- needs-check
- estimated
- deprecated
